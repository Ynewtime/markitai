# libwebp

`image.format: webp` is encoded with the lossy encoder of libwebp 1.6.0
(BSD-3-Clause; Google Inc. and the WebM project authors), built statically
into markitai from the sources vendored in `vendor/libwebp` of the markitai
repository. These files are copied unchanged from the signed release archive
`libwebp-1.6.0.tar.gz` (SHA-256 and file list in `vendor/libwebp/UPSTREAM.json`):

| File | Covers |
| --- | --- |
| `COPYING` | the libwebp license (BSD-3-Clause) |
| `PATENTS` | Google's patent grant for the WebM project's WebP implementation |
