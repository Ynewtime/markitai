# Process records

Working notes: audits, comparison runs, rejected experiments and the history
behind a decision. Each file is dated and describes one occasion, so nothing
here is maintained as current truth.

Reference documentation lives elsewhere and describes how markitai behaves
today:

- [`README.md`](../README.md) and <https://markitai.dev> — users
- [`CONTRIBUTING.md`](../CONTRIBUTING.md) — contributors
- [`webextract/PORT_MANIFEST.md`](../packages/markitai/src/markitai/webextract/PORT_MANIFEST.md) — what the defuddle port tracks
- [`scripts/benchmarks/README.md`](../scripts/benchmarks/README.md) — how to run an audit, and [`results/`](../scripts/benchmarks/results) for the recorded ones

When reference documentation needs to cite evidence, it links to a file here
rather than absorbing it.
