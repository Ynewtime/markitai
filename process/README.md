# Process records

Dated working notes: audits, comparison runs, rejected experiments. Each file
records one occasion, and nobody keeps it current afterwards.

Current behavior is documented elsewhere. Users have [`README.md`](../README.md)
and <https://markitai.dev>, contributors have
[`CONTRIBUTING.md`](../CONTRIBUTING.md), the defuddle port has
[`PORT_MANIFEST.md`](../packages/markitai/src/markitai/webextract/PORT_MANIFEST.md),
and [`scripts/benchmarks/README.md`](../scripts/benchmarks/README.md) explains
how to run an audit.
