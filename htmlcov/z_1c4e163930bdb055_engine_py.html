1"""Unified LLM call engine. 

2 

3This module is the single transport layer for LLM calls. It provides two 

4entry points: 

5 

6- ``complete_text``: plain text completions with the full transport retry 

7 loop (backoff, quota short-circuit, empty response retry) and per-attempt 

8 usage accounting. 

9- ``complete_structured``: structured (instructor-based) calls with 

10 two-layer cache lookup, transport retries, instructor validation retries, 

11 the structured-mode staircase, length checking, usage accounting, and 

12 cache write-back. 

13 

14Both entry points share one retry loop (``_acompletion_with_retries``); 

15``LLMProcessor._call_llm_with_retry`` delegates here since Phase 2.3. 

16 

17Structured calls run a capability-tiered staircase (``run_structured_ladder``) 

18whose rungs come from ``markitai.llm.structured``: the most native mode the 

19model pool supports first, one rung down per failure, ending at ``MD_JSON``. 

20JSON repair exists only on that last rung — every rung above it has the 

21provider, not the model, producing the JSON. 

22 

23This module must not import ``markitai.llm.processor`` (circular import: 

24processor -> document -> engine). 

25"""

82class RequestBudget: 

83 """Per-context LLM request circuit breaker. 

84 

85 Counts every request attempt (retries included) per usage-tracking 

86 context and refuses further requests once the limit is reached. This 

87 bounds the retry multiplication of one document: transport retries x 

88 instructor validation retries x business-level fallback chains. 

89 

90 A budget is kept per tracking context: a document's main enhancement 

91 (including its per-batch calls) shares one context, while a separate 

92 image-analysis stage tracks under its own ``...:images`` context and 

93 gets its own budget — each stage is bounded independently. 

94 """
